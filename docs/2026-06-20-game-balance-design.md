작성일: 2026-06-20

## 1. 런 구조

| 항목 | 값 |
|------|-----|
| 총 전투 횟수 | 10~12회 |
| 맵 수 | 2개 |
| 플레이어 최대 HP | 80 |

### 맵 노드 구성

**맵 1 (6노드)**
```
일반전 × 3 → 엘리트 × 1 → 상점 × 1 → 보스 × 1
```

**맵 2 (6노드)**
```
일반전 × 2 → 엘리트 × 2 → 휴식 × 1 → 보스 × 1
```

**튜토리얼 맵 (일자, 별도)**
```
전투(튜토리얼 UI 강제 안내) → 상점 → 휴식
```
- 첫 전투는 튜토리얼 UI가 플레이어의 행동을 단계별로 안내
- 기획/구현은 카드 설계 완료 후 별도 진행

## 4. 합성 레시피

| 재료1 | 재료2 | 결과 |
|-------|-------|------|
| Fire | Ice | Steam |
| Lightning | Nature | Storm |
| Dark | Light | Twilight |
| Nature | Dark | Poison |
| Light | Arcane | Holy |

### 합성 등급 결정 방식
- 합성 결과 등급은 **가중 랜덤** 방식
- 재료 카드 등급이 높을수록 높은 등급 결과 확률 증가
- 합성 카드는 상점에서 구매 불가 — **합성으로만 획득**

---

## 5. 상점 시스템

- 합성 카드(Steam/Storm/Twilight/Poison/Holy) 상점 미등장
- **리롤 필터**: 속성 1개 선택 시 해당 속성 50% + 나머지 랜덤 50% 확률로 리롤
- 카드 키워드 툴팁 없음 — 설명 텍스트에 쉬운 말로 직접 기술

---

## 6. 시작 덱

- DeckBuilder 씬에서 플레이어가 DB에서 **12장 직접 선택**
- None 기본 카드도 DB에 포함 (선택 자유)
- 합성 카드는 DB 제외 (합성 전용)
- 권장 구성: 속성 2종 각 5장 + 기본 카드 2장 (강제 아님)

## 9. 구현 우선순위 노트

1. **카드 SO 생성**: Card Creator 에디터로 60장 + 생성 전용 8장 입력
2. **적 설계**: EnemyDataSO 제작 (일반적 N종, 엘리트 M종, 보스 2종)
3. **스테이지 설계**: BattleStageSO 제작 (맵1, 맵2, 튜토리얼)
4. **연출 제작**: SkillPresentationDataSO 타임라인 (60장 우선순위 결정 필요)
5. **덱빌더 UI/UX 재설계**: 별도 grill-me 세션으로 진행
6. **튜토리얼 맵**: 카드/적 설계 완료 후 별도 구현
7. **상점 리롤 필터**: 속성 선택 드롭다운 + 50/50 확률 로직
